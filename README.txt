3D Printing Service Job and Material Usage Tracker  (COM-501, Group 11)

HOW TO RUN (VS Code)
1. Open this folder in VS Code (File > Open Folder).
2. Open main.py and press the Run button (or type:  python main.py  in the terminal).
   The final application runs from main.py.

FILES
main.py                    Final application (menu: add job / view saved jobs / exit)  - Milestone 5
print_utils.py             User-defined module with all functions                      - Milestones 4 & 5
print_logs/print_jobs.txt  Saved job records (created automatically if absent)
milestones/milestone1.py   Q1 - single job cost (run on its own)
milestones/milestone2.py   Q2 - multiple jobs using dictionary, set, loops
milestones/milestone3.py   Q3 - OOP version (class PrintJob)
milestones/milestone4/     Q4 - main.py + print_utils.py (functions, module, lambda, time)
                           (run with:  cd milestones/milestone4  then  python main.py)

Requires Python 3.8 or above. No external libraries are used.
